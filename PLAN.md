# План: улучшения CrosshairApp

**Дата:** 2026-05-20
**Сложность:** Small
**Оценка:** 1-2 часа

## Задачи

1. Настройки сохраняются после закрытия программы
2. Удобный выбор цвета (визуальный, не цифрами)

---

## Текущее состояние

**Стек:** Python + PyQt5 + Win32 API
**Файлы:**
- `main.py` - точка входа, трей, проверка единственного экземпляра
- `overlay.py` - прозрачное окно поверх всех окон с прицелом
- `control.py` - панель настроек (комбобокс прицела, 3 QSpinBox для RGB, слайдер размера)

**Что сейчас плохо:**
- При закрытии теряется выбранный прицел, цвет, размер
- Цвет вводится только цифрами в трёх отдельных полях - неудобно подбирать
- Нет пресетов популярных цветов

---

## Фаза 1: Сохранение настроек (30 минут)

**Что сохраняем:**
- Текущий файл прицела
- RGB цвет
- Размер
- Состояние видимости (включён/выключен)
- Позиция окна настроек (бонус)

**Как:**
Используем `QSettings` - встроенный в PyQt инструмент. Хранит в реестре Windows или INI файле.

Путь хранения: `HKEY_CURRENT_USER\Software\CrosshairOverlay\Settings`
(автоматически создаётся при первом сохранении)

**Что меняется в коде:**

`control.py`:
- В `__init__` после создания виджетов - вызов `_load_settings()` который читает QSettings и применяет к виджетам
- В `_on_any_change` - вызов `_save_settings()` который записывает текущие значения
- Сохранение позиции окна в `closeEvent` и `moveEvent`

`main.py`:
- Сохранять состояние visibility прицела когда нажимается F9

**Файлы:**
- `control.py` - правки
- `main.py` - правки

## Фаза 2: Визуальный выбор цвета (40 минут)

**Что добавляем:**

### 1. Кнопка с превью цвета → открывает QColorDialog

Вместо трёх QSpinBox - большая кнопка с превью цвета (например 60x40 px).
Клик → открывается стандартный диалог Windows для выбора цвета (палитра, HSV, RGB, hex).

### 2. Быстрые пресеты под кнопкой (одна строка иконок)

Популярные цвета прицелов в одну строку маленькими квадратиками-кнопками:
- Неоново-зелёный (0, 255, 0)
- Циан (0, 255, 255)
- Розовый (255, 0, 255)
- Жёлтый (255, 255, 0)
- Красный (255, 0, 0)
- Белый (255, 255, 255)
- Чёрный (0, 0, 0)
- Оранжевый (255, 128, 0)

Клик по квадратику → сразу применяется этот цвет.

### 3. Поле ручного ввода HEX (опционально)

Поле где можно вписать `#00FF00` или `00FF00` и нажать Enter → применится.
Это удобно если хочешь именно тот же цвет что в другом приложении.

### 4. QSpinBox для R/G/B оставляем но прячем под кнопкой "Расширенно"

Чтобы они не занимали место всегда, но при необходимости были доступны.

**Что меняется в коде:**

`control.py`:
- Удалить три QSpinBox из основного интерфейса (или скрыть)
- Добавить виджет `ColorPickerWidget` (новый класс или прямо inline)
- Содержит: большую кнопку-превью, ряд пресетов, поле HEX
- Сигналы те же - на изменение цвета вызывается `_on_any_change`

**Новый файл (опционально):**
- `color_picker.py` - отдельный виджет если код раздуется

## Риски

| Риск | Вероятность | Митигация |
|---|---|---|
| QSettings не работает в .exe сборке (PyInstaller) | Низкая | Указать explicit organization/application name |
| QColorDialog ломает focus прицела | Низкая | Дисциплина - открывается только из ControlPanel |
| Пресеты не помещаются по ширине | Низкая | Сделать иконки меньше или 2 ряда |

## После реализации - что протестировать

1. Закрыть программу через трей → запустить заново → настройки сохранились
2. Поменять цвет через QColorDialog → закрыть → запустить → цвет тот же
